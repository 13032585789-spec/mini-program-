# 小罚单 · 微信小程序

一个面向多人共同习惯与惩罚约定的共享记账小程序。原生微信小程序实现，无第三方运行依赖。

## 已实现

- 微信身份入口与成员邀请分享
- 图文打卡、截止时间和连续天数
- 跨日漏打卡判定与自动惩罚入账（生产环境可迁移至云函数定时执行）
- 多人共享账本、账本改名、货币切换、金额/文字惩罚、图片凭证与备注
- 周/月统计切换、趋势柱状图和成员排行
- 本地数据持久化，可无后端完整体验

## 运行

1. 打开微信开发者工具，选择“导入项目”。
2. 目录选择本项目根目录。
3. 使用测试号即可预览；发布前在 `project.config.json` 中替换正式 `appid`。

## 接入生产后端

当前数据层集中在 `utils/store.js`。生产环境可将这里的方法替换为微信云开发数据库调用，并用云函数定时任务扫描逾期打卡、生成惩罚记录；图片可上传至云存储。
